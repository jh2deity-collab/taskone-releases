# TaskOne 내려받기

프로젝트 · 작업 · 결재 · 업무양식 · 메신저를 한곳에서 관리하는 업무 협업 도구 **TaskOne**의 설치 파일 배포 페이지입니다.

## 👉 [최신 버전 내려받기](https://github.com/jh2deity-collab/taskone-releases/releases/latest)

| 파일 | 어디에 | 설명 |
|---|---|---|
| `TaskOne-Setup-<버전>.exe` | Windows PC | 설치 프로그램 · PC 앱 겸 팀 서버 · 관리자 권한 불필요 |
| `TaskOne-<버전>.apk` | 안드로이드 휴대폰 | 휴대폰 단독 실행 · 같은 와이파이에서 PC와 자동 동기화 · Android 7.0 이상 |
| `TaskOne-Portable-<버전>.zip` | Windows PC | 설치 없이 압축만 풀어 쓰는 휴대용 |

## 설치

### Windows
1. `TaskOne-Setup-<버전>.exe` 를 실행합니다.
2. 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행**을 누릅니다 (코드 서명 전이라 처음 한 번 나타나요).
3. 이미 설치돼 있으면 데이터 · 설정은 그대로 두고 새 버전으로 바뀝니다.

### 안드로이드
1. 휴대폰에서 `TaskOne-<버전>.apk` 를 내려받아 엽니다.
2. **이 출처 허용 → 설치** (Play 프로텍트 경고가 뜨면 **무시하고 설치**).
3. 처음 실행하면 「이 휴대폰에서 시작」 또는 「PC와 연결」을 고릅니다.

### 휴대폰과 PC 연결
1. PC의 TaskOne › **설정 › 모바일 앱** › 「휴대폰 접속 허용」을 켭니다 (관리자).
2. 휴대폰 앱의 **설정 › 모바일 앱**에 PC 화면의 주소와 6자리 코드를 입력합니다.
3. 같은 와이파이에서는 실시간으로, 밖에서 바꾼 내용은 와이파이에 돌아오면 자동으로 맞춰집니다.

### iPhone
iPhone 전용 앱은 아직 없어요. PC와 같은 와이파이에서 Safari로 PC 주소를 열고 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 무결성 확인
각 파일 옆의 `.sha256.txt` 값과 내려받은 파일의 해시를 비교하세요.
```
certutil -hashfile TaskOne-Setup-1.3.0.exe SHA256
```

데이터는 사용하는 PC(팀 서버)와 휴대폰에만 저장되고, 외부 서버로 보내지 않습니다.
